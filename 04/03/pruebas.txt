== 5. Nginx como reverse proxy ==

$ cat > nginx/nginx.conf <<'EOF'
server {
    listen 80;

    location / {
        proxy_pass http://api:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF

$ cat > docker-compose.yml <<'EOF'
services:
  api:
    build: ./app
    container_name: api
    expose:
      - "5000"

  nginx:
    image: nginx:alpine
    container_name: nginx
    ports:
      - "80:80"
    volumes:
      - ./nginx/nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - api
EOF

$ docker compose down
[+] down 2/2
 ✔ Container api           Removed
 ✔ Network ec2-lab_default Removed

$ docker compose up -d --build
[+] up 15/15
 ✔ Image nginx:alpine      Pulled
 ✔ Image ec2-lab-api       Built
 ✔ Network ec2-lab_default Created
 ✔ Container api           Started
 ✔ Container nginx         Started

Nota: al intentar pegar las líneas YAML de `environment:` directamente en la
shell, bash interpretó `environment:` como un comando y respondió
`command not found`. Se corrigió editando docker-compose.yml con nano; luego
`docker compose up -d --build` reconstruyó la API y el reto respondió
correctamente.
